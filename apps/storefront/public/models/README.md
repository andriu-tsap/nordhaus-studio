Modele GLB: jednostka 1 m, oś Y do góry, origin na podłożu, zastosowane transformacje. W Blenderze: File → Export → glTF 2.0 → GLB, Include Selected Objects, +Y Up. Zalecane < 50 tys. trójkątów i tekstury ≤ 1024 px.
